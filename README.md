# 小明智能体 · 中文待办清单

基于[词元启明实战题模板](https://github.com/TokeNow/todo-agent)实现的中文待办清单智能体。支持通过自然中文对话创建、查看、修改、完成、取消完成和删除任务，所有任务持久化保存在本地 `data/tasks.json`，右侧任务看板随对话实时同步。

## 核心架构

- **DeepSeek Tool Calling 智能体模式（推荐）**：配置 `DEEPSEEK_API_KEY` 后，由 DeepSeek 模型通过标准 Function Calling 多轮工具循环（`list_tasks`、`create_tasks`、`update_task`、`delete_task`、`get_schedule_overview`）直接驱动对话，支持口语语义匹配、上下文消歧、一次多任务创建、子任务拆解与日程规划。
- **离线规则降级模式（零密钥可试用）**：未配置 API Key 时自动降级到本地中文规则解析器，无需密钥即可直接体验基础验收与全部扩展能力；页面顶栏实时显示当前运行模式。
- **统一存储与向后兼容**：Agent 工具层与 REST API 共享注入的 `TaskStore`，保持原 OpenAPI 端点与 JSON 扩展字段兼容。接口定义见 [server/openapi.yaml](server/openapi.yaml)。

## 快速开始

安装 Node.js 24.12 或更高版本，在项目根目录执行：

```sh
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:3000> 即可使用。

### 接入 DeepSeek（启用完整智能体能力）

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填入自己的 `DEEPSEEK_API_KEY`（`.env` 已被 `.gitignore` 忽略，不会被提交到仓库）。默认模型 `deepseek-flash` 会使用低延迟模式，可通过 `DEEPSEEK_REASONING_EFFORT`（`none` / `low` / `medium` / `high` / `max`）按需调整思考强度。
3. 重启 `npm run dev`。页面右上角显示 `已配置 · deepseek-flash` 时，智能体会把近期对话及工具查询结果发给 DeepSeek。留空 `DEEPSEEK_API_KEY` 可在本地离线使用。

更多开发与接口调试方式见[本地开发指南](GETTING_STARTED.md)。

## 已完成功能

### 基础能力

- 中文自然语言 **新增 / 查看 / 标记完成 / 取消完成 / 改标题 / 删除** 待办。
- 本地 JSON 原子持久化（`data/tasks.json`），刷新页面或重启服务后任务完整保留。

### 扩展能力

- **到期日与逾期提醒**：支持「今天」「明天」「后天」「大后天」「本周X」「下周X」及 `YYYY-MM-DD`，按服务端本地时区计算。问「今天有哪些任务到期？」时会列出今天到期任务，并单独提醒已逾期未完成的任务。
- **优先级与工作量**：支持高/中/低优先级（1/2/3）与小/中/大工作量，支持后续修改或清除。
- **一层子任务管理**：支持为主任务添加、完成、删除子任务；子任务全部完成时主动提醒主任务状态；删除主任务时子任务自动转为独立任务。
- **可视化联动看板**：右侧任务面板按「已逾期 → 今日到期 → 高优先级 → 普通」自动排序，树形缩进展示子任务及完成进度，提供 `全部 / 待办 / 今日 / 已完成` 视图筛选、进度条、直接勾选/删除以及对话变更后的高亮反馈；窄屏自动折叠为顶部抽屉。
- **写入确认与消歧**：DeepSeek 批量删除先列出目标，回复「确认删除」后才执行。同名任务优先按意图匹配状态，多条相似候选可用序号指定。

## 如何验证

### 1. 自动化测试与代码检查

```sh
npm test
npm run typecheck
npm run lint
npm run fmt:check
npm run build
```

`npm test` 涵盖原仓库全部任务与聊天 API 测试、离线 6 句验收与重启持久化、消歧与边界测试、到期/优先级/工作量/子任务测试，以及 Mock DeepSeek Tool Calling 多轮链路与错误恢复测试。

### 2. 页面交互验收

在空清单状态下，依次对小明发送以下 6 句对话，观察回复和右侧任务看板同步变化，最后刷新页面或重启服务再查清单：

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

扩展功能体验示例：

- 「帮我记一下今天交报告，优先级高，工作量中」→「给交报告加子任务整理资料」→「今天有哪些任务到期？」
- 「帮我记一下买牛奶和取快递」→「把买牛奶改名为买脱脂牛奶」→「取消完成买脱脂牛奶」
