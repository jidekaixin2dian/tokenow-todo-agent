# 小明智能体 · 中文待办清单

用中文对话新增、查看、完成和删除待办。任务保存在本地，右侧清单随对话更新。项目基于[词元启明的实战题模板](https://github.com/TokeNow/todo-agent)。

## 快速开始

安装 Node.js 24.12 或更高版本，在项目根目录运行以下命令。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>，无需密钥即可试用下方的验收对话和扩展功能。

要让小明理解更多口语表达和上下文指代，可以将 `.env.example` 复制为 `.env`，填入自己的 `DEEPSEEK_API_KEY` 并重启服务。本地无法识别的说法才会发给 DeepSeek，最多带上最近八条对话消息。详见[本地开发指南](GETTING_STARTED.md)。

## 验证方式

在空清单中依次发送以下消息，观察回复和任务清单。最后刷新页面或重启服务，再问「看看我的待办」，仍能看到已完成的「买牛奶」。

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

运行 `npm test` 可验证同一段对话、持久化、相似任务的处理、扩展字段和模拟 DeepSeek 返回。

## 扩展功能

- **到期日。** 说「帮我记一下今天交报告」，再问「今天有哪些任务到期？」。日期按服务所在机器的本地时区计算。
- **优先级和工作量。** 说「帮我记一下周会备稿，优先级高，工作量中」，也可以说「把周会备稿的工作量改为小」。
- **子任务。** 先创建「交报告」，再说「给交报告加子任务整理资料」。子任务可以单独完成或删除。删除主任务时，其子任务会转为独立任务。
- **清单展示。** 待办与已完成分组，显示日期、优先级、工作量和所属主任务。窄屏可从顶部打开清单。
- **消歧。** 有多条任务符合时，小明会列出编号。使用「删除 #编号」或「完成 #编号」可以明确指定一条。

`server/agent.ts` 接收对话历史，使用和任务 API 相同的 JSON 存储执行操作。任务接口详见 [OpenAPI 说明](server/openapi.yaml)。
